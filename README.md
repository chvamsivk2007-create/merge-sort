# Merge Sort 🔀

C++ program to sort array elements using the **Merge Sort** technique.

---

## 📖 Description
- Divide and conquer algorithm
- Recursively splits the array into halves
- Merges sorted halves back together
- Time Complexity: O(n log n)

---

## ▶️ Compilation & Run
```bash
g++ merge_sort.cpp -o merge_sort
./merge_sort
